# Project identity

Public name: **Netflix Trend Forecasting**. Subtitle: **Historical time series**.

The header, section headings, footer, document title and description use the project identity consistently across all project sections. This is an independent portfolio project with no Netflix affiliation.

The forecasting symbol is shared by `logo.svg`, `favicon.svg`, the multi-resolution ICO and the Apple touch icon. White geometric marks on a black square keep the existing visual system. Icon URLs use version 2 to refresh cached assets.

The logo assets share a single geometric symbol across SVG, ICO and Apple touch icon formats. Semantic colors in data visualizations are independent of the monochrome identity.

Selected section links remain visible on cold direct loads: the navigation observes link dimensions as well as its container and rechecks visibility once fonts finish loading. Verification deliberately delays web fonts before rotating from tablet to phone.
