# Project capabilities

Analyze annual release-year cohorts and monthly catalog additions using historical time series. Compare chronological backtests, inspect frozen forecasts and disclose baseline failures. Projections are relative to historical fitting origins rather than the current date.

| Capability | Implementation and evidence |
| --- | --- |
| Prepare time-based features | Source audit, contiguous series, lag/rolling/calendar features; alignment and chronology tests |
| Analyze historical release patterns | Annual release-year history, source coverage, observed growth/flattening, supplementary additions, notebook/report |
| Build forecasting models | Eight annual/nine monthly candidate specifications, baselines, Ridge/forest fits, frozen comparison and selection |
| Generate future predictions | Saved historical-origin projections, 3 years/6 months, four-page website, scope/horizon controls and CSV export |
| Evaluate forecasting accuracy | Expanding CV, untouched chronological test, MAE/RMSE/sMAPE/WAPE/MASE, baseline and per-period error analysis, band coverage |

The web application has five sections: `/overview`, `/dataset`, `/forecast`, `/evaluation` and `/methodology`. All displayed model results come from a validated saved run. Inspect [methodology](methodology.md), [model card](model-card.md) and [verification](../VERIFICATION.md) for practical limits and recorded checks.
